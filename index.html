⚡ ÆEA ENGINE · MQL4-PARITY PORT · TWA v4.1.0

TOOLBAR — Symbol picker, timeframe picker, chart-type toggle, view switcher (CHART / 13D / REGIME), indicator adder, FVG list, refresh, settings, help.
CHART — Interactive candlestick chart with crosshair, pan, zoom, tap-to-inspect. Overlays: Bollinger Bands (Premium/Discount), FVG lines (Top/Bott), signal markers (▲BUY / ▼SELL), trailing-stop line.
SUB-PANELS — MT4-style indicator sub-windows. Add via + IND. Each panel has a header with title, current value, and visibility/settings/close controls.
13D GRID — The 13 classical indicators projected onto the Hilbert space H₁₃, each normalized to [0, 100], with live bars and historical sparkline.
REGIME MAP — Per-bar regime classification: sRange / sVolatile / sTrend / Stable, with time-extension variants (tRange / tVolatile / tTrend).
KRONECKER δ — δ(m−n−2). m = overbought indicator count, n = oversold count. H() fires when m ≥ 12, L() fires when n ≥ 12.
ENGINE PANEL — KC / prime / dime / mem / tag / invert / A / B / C / c / tick_tock / signature / trailing / OnTrack / OnStand / orders / safety.
DERIVATIVE PANEL — Z / z / O / o / W / w / I / iI / J / iJ / X_scan / Y_scan / S / T / r / ir / iATR / iStdDev / iIHKk / iIHKt.
ORDER TICKET — Place simulated orders with lot/SL/TP. Close individual positions or all at once. Positions list shows entry, SL, TP, PnL.
FVG — Long-press on chart to draw a Top/Bott FVG. Tap an FVG line to delete. The FVG button in the toolbar shows the full list.
LOG BAR — Last engine events. Tap to expand to the full log.
Keyboard: C=chart | G=grid | R=regime | H=help | F5=refresh | Esc=close modal.
