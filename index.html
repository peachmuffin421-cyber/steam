⚡ ÆEA ENGINE · MQL4-PARITY PORT · TWA v4.5.0

TOOLBAR — Symbol picker, timeframe picker, chart-type toggle, view switcher (CHART / 13D / REGIME), indicator adder, FVG list, BB×58 toggle, V toggle, refresh, settings, help.
CANDLES — Bullish = blue, bearish = red (MQL4 clrBlue/clrRed parity).
VOLUME PANE — Tick volume histogram below the candlesticks. Bar height proportional to bar.volume normalized by the maximum volume in the visible range. Bullish volume bars = blue, bearish = red. Toggle via the V button. Rendered on the #volumeOverlay canvas at z-index: 4. Volume data is sourced from the relay (Binance for crypto, Yahoo for equities/futures) and propagated through /ohlcv.
BOLLINGER FAMILY — All 58 BB pairs for periods 3..60 (MQL4 iBands parity: dev=2, close, shift=0, population σ). Computed on the backend in exact Decimal arithmetic and fetched via GET /bb-family. Upper bands: green gradient. Lower bands: white gradient. The frontend performs zero BB arithmetic; it is a pure renderer.
TOASTS + PUSH — σ toasts fire on every _signal(); execution toasts fire on every dispatch; FVG toasts fire on every anchor commit/remove. Each toast triggers a Telegram sendMessage push to the bound chat, threaded as a reply to your most recent command — the bot responds to the user on every event, causing a native push notification.
Π_r — The relay dispatches crypto symbols to Binance klines (real volume) with CoinGecko fallback and Yahoo tertiary. Equities/futures use Yahoo only. The current provider is shown in the Engine Panel.
CHART — Interactive candlestick chart with crosshair, pan, zoom, tap-to-inspect. Overlays: BB family, topological anchors (Π/Δ), FVG lines, signal markers, trailing-stop line, volume histogram.
SUB-PANELS — MT4-style indicator sub-windows. Add via + IND.
13D GRID — The 13 classical indicators projected onto H₁₃, normalized to [0, 100].
REGIME MAP — Per-bar regime classification: sRange / sVolatile / sTrend / Stable, with time-extension variants.
δ(m−n−2) — δ(m−n−2). m = overbought count, n = oversold count. H() fires when m ≥ 12, L() fires when n ≥ 12.
ENGINE PANEL — K_C / π' / δ_m / μ_m / τ_g / I_v / A / B / C / c / tick_tock / signature / trailing / OnTrack / OnStand / orders / safety / Π_r / V / λ_m.
DERIVATIVE PANEL — Z / z / O / o / W / w / I / iI / J / iJ / X_s / Y_s / S / T / r / i_r / i_ATR / i_σ / i_IHKk / i_IHKt.
ORDER TICKET — Place simulated orders with lot/SL/TP. Numeric fields accept exact decimal strings.
FVG — Long-press on chart to draw a ▲/▼ FVG. Tap an FVG line to delete.
LOG BAR — Last engine events. Tap to expand to the full log.
Keyboard: C=chart | G=grid | R=regime | V=volume toggle | H=help | F5=refresh | Esc=close modal.
