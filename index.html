⚡ ÆEA ENGINE · MQL4-PARITY PORT · TWA v4.3.0

TOOLBAR — Symbol picker, timeframe picker, chart-type toggle, view switcher (CHART / 13D / REGIME), indicator adder, FVG list, BB×58 toggle, ARC projection toggle, refresh, settings, help.
CANDLES — Bullish = blue, bearish = red (MQL4 clrBlue/clrRed parity).
BOLLINGER FAMILY — All 58 BB pairs for periods 3..60 (MQL4 iBands parity: dev=2, close, shift=0, population σ). Upper bands: green gradient. Lower bands: white gradient. v4.3.0 computes σ via BigInt-backed exact arithmetic.
ARC PROJECTION — Forward price path derived from the s=r coherence condition. Three branches: range (cosine arc from price to signal), trend (linear extension along slope), volatile (damped oscillation across Premium/Discount band). Drawn dashed ahead of the last bar. All arithmetic is Decimal-exact on the backend.
TOASTS + PUSH — Signal toasts fire on every _signal(); execution toasts fire on every dispatch; FVG toasts fire on every anchor commit/remove. Each toast triggers a Telegram sendMessage push to the bound chat — the bot responds to the user, causing a native push notification.
PROVIDER — The relay dispatches crypto symbols to Binance klines (real volume) with CoinGecko fallback and Yahoo tertiary. Equities/futures use Yahoo only. The current provider is shown in the Engine Panel and the Projection Panel.
CHART — Interactive candlestick chart with crosshair, pan, zoom, tap-to-inspect. Overlays: BB family, topological anchors (Premium/Discount), FVG lines, signal markers, trailing-stop line, arc projection.
SUB-PANELS — MT4-style indicator sub-windows. Add via + IND.
13D GRID — The 13 classical indicators projected onto H₁₃, normalized to [0, 100].
REGIME MAP — Per-bar regime classification: sRange / sVolatile / sTrend / Stable, with time-extension variants.
KRONECKER δ — δ(m−n−2). m = overbought count, n = oversold count. H() fires when m ≥ 12, L() fires when n ≥ 12.
ENGINE PANEL — KC / prime / dime / mem / tag / invert / A / B / C / c / tick_tock / signature / trailing / OnTrack / OnStand / orders / safety / provider / volume.
DERIVATIVE PANEL — Z / z / O / o / W / w / I / iI / J / iJ / X_scan / Y_scan / S / T / r / ir / iATR / iStdDev / iIHKk / iIHKt.
PROJECTION PANEL — Branch / horizon / slope / amplitude / center / damping / provider / next / end / updated.
ORDER TICKET — Place simulated orders with lot/SL/TP. Numeric fields accept exact decimal strings.
FVG — Long-press on chart to draw a Top/Bott FVG. Tap an FVG line to delete.
LOG BAR — Last engine events. Tap to expand to the full log.
